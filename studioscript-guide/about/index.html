Acerca de StudioScript Guide

Qué es este sitio

StudioScript Guide es un proyecto independiente de tutoriales para quien empieza con Roblox Studio y con el lenguaje de programación Lua (en Roblox, Luau). La idea es explicar cada tema en pasos cortos, con código que se puede copiar y con enlaces a la documentación oficial.

Quién está detrás del sitio

StudioScript Guide es un proyecto independiente. Esta página no publica datos personales del responsable. El contenido está dirigido a personas que están empezando y debe utilizarse como material de aprendizaje, comprobando los ejemplos en un proyecto de prueba.

Cómo usar las guías

  • Lee todos los pasos antes de ejecutar el código.
  • Prueba los ejemplos en un proyecto de prueba, no en una experiencia publicada que sea importante para ti.
  • Consulta las fuentes oficiales, como la documentación de Roblox y el sitio de Luau.
  • Las interfaces y las APIs pueden cambiar; verifica la documentación actual si algo no coincide.

Correcciones y sugerencias

Si encuentras un error o quieres proponer un tema, consulta la página de contacto; el canal de comunicación todavía no está habilitado.
