Tu primer script en Roblox Studio con Lua

En esta guía crearás un Script, imprimirás un mensaje, cambiarás el color de una pieza y harás que reaccione cuando algo la toque.

Requisitos

  • Roblox Studio instalado e iniciado con tu cuenta de Roblox. Consulta la documentación oficial si necesitas ayuda con la instalación.
  • No hace falta saber programar.

Al terminar sabrás usar print, crear variables con local, cambiar una propiedad de un objeto y conectar una función a un evento.

Lua y Luau

Los scripts de Roblox se escriben en Luau, un lenguaje derivado de Lua 5.1 que mantiene Roblox. Para lo básico es muy parecido a Lua, por eso muchos materiales hablan simplemente de «Lua». Puedes ampliar información en el sitio oficial de Luau.

Paso 1: crea un proyecto

  1. Abre Roblox Studio e inicia sesión.
  2. Elige la plantilla Baseplate (una plataforma plana y vacía).
  3. Espera a que cargue el proyecto.

La interfaz de Studio cambia con el tiempo. Si algún nombre de botón o menú no coincide con esta guía, busca el equivalente en la documentación oficial.

Paso 2: abre las ventanas Explorer, Properties y Output

Vas a usar tres ventanas. Explorer muestra los objetos del proyecto, Properties muestra las propiedades del objeto seleccionado y Output muestra los mensajes de tus scripts.

  1. Abre la pestaña View.
  2. Pulsa Explorer, Properties y Output para mostrar las que no estén visibles.

Paso 3: inserta una pieza

  1. En la pestaña Home, pulsa Part. Aparecerá una pieza (un bloque) en el mundo.
  2. Selecciónala en Explorer.
  3. En Properties, busca Name y escribe PiezaPrueba.
  4. En Properties, comprueba que Anchored está marcada. Si no lo está, la pieza caerá por la gravedad al ejecutar el juego.

Paso 4: añade un Script a la pieza

  1. En Explorer, pasa el ratón sobre PiezaPrueba.
  2. Pulsa el botón + que aparece a la derecha del nombre.
  3. En el menú, elige Script.
  4. Haz doble clic en el nuevo Script para abrir el editor de código.

Un Script nuevo trae una línea de ejemplo que imprime un saludo. Ahí empezamos.

Paso 5: ejecuta y lee Output

Sustituye todo el contenido del Script por este código:

-- Mi primer script
print("¡Hola desde mi primer script!")

Las líneas que empiezan por -- son comentarios: Lua las ignora y sirven para dejar notas. print escribe un mensaje en la ventana Output.

  1. Abre la pestaña Test y pulsa Play.
  2. Mira la ventana Output: debe aparecer el mensaje.
  3. Pulsa Stop para volver al editor.

Paso 6: usa una variable para referirte a la pieza

Cambia el código por este:

local pieza = script.Parent
print("Mi pieza se llama: " .. pieza.Name)
  • script es el propio Script. Su propiedad Parent es el objeto que lo contiene; en este caso, la pieza.
  • local pieza = … crea una variable llamada pieza que guarda ese objeto.
  • Los dos puntos .. unen textos. Aquí unen un mensaje con el nombre de la pieza.

Ejecuta con Play. En Output debe aparecer el nombre que pusiste en el paso 3.

Paso 7: cambia el color de la pieza

local pieza = script.Parent

pieza.Color = Color3.fromRGB(255, 0, 0)

Color es una propiedad de la pieza. Color3.fromRGB(rojo, verde, azul) crea un color con tres valores entre 0 y 255. Con 255, 0, 0 obtienes rojo. Ejecuta el juego y comprueba que la pieza cambia de color.

Prueba tú: cambia los tres números y vuelve a ejecutar. Lua distingue mayúsculas de minúsculas: Color no es lo mismo que color.

Paso 8: reacciona al contacto con Touched

Un evento avisa de que ha ocurrido algo. Touched se dispara cuando otro objeto toca la pieza. Con :Connect(…) le indicas qué función debe ejecutarse cuando eso pase.

local pieza = script.Parent

local function alTocar(otraPieza)
    print("Algo ha tocado la pieza:", otraPieza.Name)
    pieza.Color = Color3.fromRGB(0, 170, 255)
end

pieza.Touched:Connect(alTocar)
  1. Pulsa Play.
  2. Mueve tu personaje hasta que toque la pieza.
  3. Mira Output: aparecerá el nombre de la parte de tu personaje que ha tocado la pieza, y la pieza cambiará a azul.

Es normal que el mensaje aparezca varias veces seguidas: Touched puede dispararse repetidamente mientras hay contacto.

Problemas frecuentes

  • No aparece nada en Output. Comprueba que la ventana está abierta (pestaña View). Revisa también que el Script esté dentro de la pieza y que la pieza esté en Workspace.
  • Hay texto en rojo en Output. Es un error. Lee el mensaje: indica el nombre del script y el número de línea donde falla.
  • La pieza cae al suelo. Marca la propiedad Anchored en Properties.
  • No pasa nada al tocar la pieza. Asegúrate de que tu personaje llega a tocarla y de que el código está escrito exactamente como en el ejemplo, respetando mayúsculas y minúsculas.
